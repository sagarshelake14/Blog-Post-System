# 📝 Blog Post System

A modern and responsive **Blog Post Management System** built with **React.js** and **Appwrite**. This application allows users to securely create, edit, publish, and manage blog posts with authentication, rich text editing, image uploads, and protected routes.

---

## ✨ Features

- 🔐 User Authentication (Sign Up, Login & Logout)
- 📝 Create, Edit, and Delete Blog Posts
- 📖 View Published Blog Posts
- 🖼️ Upload Featured Images using Appwrite Storage
- ✍️ Rich Text Editor (TinyMCE)
- 🔒 Protected Routes for Authorized Users
- 📱 Responsive Design
- ⚡ Fast Navigation using React Router
- 📦 Global State Management with Redux Toolkit
- ☁️ Backend powered by Appwrite
- ❌ Form Validation and Error Handling

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- Redux Toolkit
- Tailwind CSS
- TinyMCE Editor
- React Hook Form

### Backend (BaaS)
- Appwrite Authentication
- Appwrite Database
- Appwrite Storage
